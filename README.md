# Teja Narayana — Portfolio

Personal portfolio for **Teja Narayana**, Product Engineer working at the intersection of product, AI, and engineering.

Built with **SvelteKit**, **Svelte 5**, and **Tailwind CSS v4**.

## Run locally

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Scripts

| Command         | Description                    |
| --------------- | ------------------------------ |
| `npm run dev`   | Start the Vite dev server      |
| `npm run build` | Production build               |
| `npm run preview` | Preview the production build |
| `npm run check` | Typecheck with svelte-check    |
| `npm run lint`  | Prettier + ESLint              |
| `npm run format`| Format with Prettier           |

## Stack

- SvelteKit + TypeScript
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Typography plugin for long-form content hooks

## Content

Site copy is drawn from [aejt.in](https://www.aejt.in) — especially the authentic journey (GXCO, product analysis, IEEE research, ACM Winter School) — rewritten into a more visual, less text-heavy landing experience.
